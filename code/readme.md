## layout

| folder | content |
|---|---|
| `code/` | main analysis chain (all stages: `itrusst_rerun_all.m`, see top-level README): phantoms, calibration, `PRESTUS_paramvar_00-04`, `PRESTUS_pipeline_01-02`, `PRESTUS_thickness_01-07`, setup/range figures |
| `code/functions/` | shared helpers called by the scripts (no script runs from here) |
| `code/paper/` | panels of the paper figures (`paper_fig*`, `paper_supp_fig*`), absorption placed directly after attenuation, and the supplementary table of setup and toolbox-default properties (`paper_supp_table_setups`), stage `itrusst_rerun_all('plot-paper')`; output in `figures/paper/fig<N>/`, `figures/paper/supp_fig<N>/` and `figures/paper/supp_table/` |

Scripts must be run as files (they resolve `rootpath` from their own location) and add `code/functions` to the path themselves.

`code/explore/` (side analyses) and `code/debug/` (numerical checks) are kept locally and not tracked.

Figures are written to `figures/<family>/` with the same split: `paper/`, `tissue_ranges/`, `setups/`, `pipeline/`, `paramvar/`, `thickness/`, `explore/<topic>/`, `debug/<topic>/`. Design tables of multi-run designs are written next to their simulation output in `data/tussim/<variant>/`.

## model overview

All models are digital phantoms: tissue-label volumes (`data/simnibs/m2m_sub-XXX/final_tissues.nii.gz`) generated by `createPhantom.m` and `PRESTUS_thickness_01_createPhantoms.m`; `sub-XXX` labels a geometry, not a participant.

sub-001 | soft-tissue only, 64 mm focus (2D axisymmetric, 0.5 mm)
sub-002 | soft-tissue + skull, 64 mm focus (2D axisymmetric, 0.5 mm)
sub-003 | soft-tissue + skull with cortical/trabecular layers (multiskull, explore)

sub-101/102 | 3D phantoms of sub-001/002 (pipeline comparison; axisymmetric acoustics, thermal on the radially expanded 3D field)
sub-201/202 | 0.25 mm counterparts of sub-001/002 (debug)
sub-301..312 | skull thickness 1..12 mm
sub-351..361 | skull thickness 1.5..11.5 mm (see `itrusst_thickness_subjects.m`)

## shared utilities (`code/functions/`)

### `setup_itrusst_paths.m`

```matlab
pn = setup_itrusst_paths(rootpath, user)
```

Sets up `pn.prestus` (`tools/PRESTUS`), `pn.kwave`, `pn.minimize`, `pn.configs`, `pn.data`, `pn.path_seg`, `pn.code` and `pn.platform` (job submission: `slurm`/`qsub` if a scheduler is on the PATH, otherwise `matlab`; `setenv('ITRUSST_PLATFORM', 'matlab')` forces local runs), and adds the toolbox folders to the MATLAB path. Call after `addpath(fullfile(rootpath, 'code', 'functions'))`.

### `load_paramvar_results.m`

```matlab
[results, xlabels] = load_paramvar_results(data_dir, subject_id, ...
    tissue_labels, tissue_suffixes, property_labels, property_suffixes, sweep_values, property_symbols)
```

Reads `sub-XXX_phantom<affix>.csv` per tissue x property x sweep level and returns `results` with fields `sweep`, `Ipa_target`, `maxT` (rise from 37 °C), `Isppa_brain`, `riseT_brain`, `Isppa_skull`, `riseT_skull`, `real_focal_distance_mm`, `focal_vol_3dB_mm3` (each `[n_sweep x n_conds]`) and condition labels `xlabels` (TeX symbols if `property_symbols` is given). Missing files/columns are warned and left as `NaN`.

### `load_focus_heating_metrics.m`

Same inputs as `load_paramvar_results`; reads the heatrise NIfTIs at the empirical focus voxel (`riseT_focus`) and at the fixed nominal target (`riseT_target`).

### `load_babelbrain_benchmark2.m`

```matlab
[results, ref, xlabels] = load_babelbrain_benchmark2(data_dir, ppw, tissue_labels, property_labels, property_symbols)
```

Reads the BabelBrain paramvar results of benchmark 2 (Sam Pichardo; newest `data/pichardo/Benchmark2-<date>-<ppw>PPW.csv`, 6 or 9 points per wavelength) in the layout of `load_paramvar_results` (rows LOW/HIGH = sweep level 1/2). Fields `Isppa_brain`, `MI_brain`, `riseT_brain`, `riseT_skull`, `riseT_target` (fixed target), `CEM43_brain`, `CEM43_skull`; `ref` holds the `Reference` row. PRESTUS vs BabelBrain 6/9 PPW differences: `PRESTUS_paramvar_02_benchmark2_babelbrain_plot.m` (`figures/paramvar/babelbrain/`).

### `plot_metric_with_patches.m`, `make_parallel_plot.m`

Range plot (min-max patch per condition, bottom/top levels as dots; brain grey, skull red) and parallel-coordinates plot of the setup property tables.

### `itrusst_calibrate.m`, `itrusst_apply_calibration.m`, `itrusst_thickness_subjects.m`

Free-water calibration of the annular transducer to a target intensity; copy of the calibrated drive (`annular: {...}` block of `data/calibration/PRESTUS_virtual_parameters/<setup>-F*mm-I*wpercm2.yaml`) into `config_<setup>.yaml`; mapping between skull thickness (mm) and thickness-phantom subject IDs.

### `itrusst_tissue_properties.m`, `itrusst_write_medium_configs.m`, `itrusst_resolve_absorption.m`, `itrusst_level_absorption_coeff.m`

Tissue properties of a setup (`heat_max`, `heat_min`, `trans_max`, `trans_min`, `reference`, `bottom`, `top`) from `data/tissue_parameters.csv` + `tissue_setups.csv`; generation of `data/configs/config_medium_<setup>.yaml` from them. `itrusst_resolve_absorption.m` sets each tissue's `absorption_coeff`: brain from `absorption_fraction` × the attenuation it is combined with, skull and water from their coefficient, capped at the attenuation (absorption ≤ 100 %). It is applied to every assembled medium (setups, one-at-a-time sweep, thickness sweeps, baseline). `itrusst_level_absorption_coeff.m` gives the brain coefficient per CSV level (fraction × attenuation of the same level) for the range figures. The factorial and Morris designs (`explore/PRESTUS_paramvar_08`, `_09`, untracked) use the same resolution.

### `itrusst_backup_outputs.m`

Moves `data/tussim`, `data/calibration` and `figures/*` aside under a date tag before a rerun, keeping the I/O paths.

### paper panels (`code/paper/`, helpers `paper_*.m` in `code/functions/`)

Panels at print size (8 pt Helvetica, axes boxes fixed in cm via `paper_style.m`), saved as vector PDF + 300 dpi PNG by `paper_save.m` for assembly in Illustrator. Properties are ordered sound speed, density, attenuation, absorption, thermal conductivity, specific heat capacity, perfusion. Run them all with `itrusst_rerun_all('plot-paper')` (independent of the slower diagnostic `plot` stage). Schematics, icons, legends and frames are added there. BabelBrain panels (benchmark 2 = sub-002, collaborator results in `data/pichardo/`, see `load_babelbrain_benchmark2.m`) are drawn next to their PRESTUS counterparts on a shared y-range; `paper_placeholder.m` (empty panel with the neighbouring axes) remains for collaborator panels without data.

Two inputs are not tracked in the repository: the BabelBrain CSVs (default `data/pichardo/`, override with `setenv('ITRUSST_BABELBRAIN_DIR', '<folder>')`) and the ITRUSST acoustic-properties table (default `../itrusst_properties/literature_web/data/measurements.csv`, a clone of `itrusst_acousticproperties`, override with `setenv('ITRUSST_MEASUREMENTS_CSV', '<file>')`). Scripts that need them stop with an error naming the missing path and the variable (`itrusst_input_path.m`).

Thermal reference lines need a reference-medium (`_baseline`) run, which `PRESTUS_paramvar_00_baseline_sim.m` provides for sub-001, sub-002 and sub-352.
